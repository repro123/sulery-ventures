    answer: "There is no fixed number that is suitable for every property. The number of cameras depends on the size and layout of the property, the areas you want to monitor and the level of coverage required."
  - question: "Can I view my CCTV cameras from my phone?"
    answer: "Many modern CCTV systems support remote viewing, provided the equipment and network are configured appropriately. We can help set up remote viewing where the system supports it."
  - question: "Can you repair an existing CCTV system?"
    answer: "Yes. We can help troubleshoot existing CCTV systems and identify problems involving cameras, recording equipment, connections, cabling, network connectivity and remote viewing."
  - question: "Do I need to replace my entire CCTV system if one camera stops working?"
    answer: "Not necessarily. Depending on the cause of the problem and the condition and compatibility of the existing equipment, it may be possible to repair or replace only the affected component."
  - question: "Can CCTV be installed in a home?"
    answer: "Yes. CCTV systems can be installed in residential properties to monitor selected areas such as entrances, gates, driveways and compounds."
  - question: "Can you install CCTV for a business?"
    answer: "Yes. We provide CCTV installation and related services for businesses and other organisations."
  - question: "Can you help me choose a CCTV system?"
    answer: "Yes. If you're unsure what equipment or setup is appropriate, tell us about the property and what you want to monitor. We can discuss the available options with you."
  - question: "My CCTV is showing a black screen. Can you help?"
    answer: "Yes. A black screen can have several possible causes, including power, cabling, camera, display, recording or configuration issues. We can help troubleshoot the system."
  - question: "My CCTV used to work remotely but no longer does. What should I do?"
    answer: "Remote viewing can stop working for several reasons, including changes to the network, equipment configuration or connectivity. Contact us and describe the problem so we can help troubleshoot it."
  - question: "How often should CCTV systems be maintained?"
    answer: "The appropriate maintenance schedule depends on the equipment, environment and how the system is used. Regular checks can help identify faults before they become more disruptive."
